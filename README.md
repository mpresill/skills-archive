Personal archive of Claude Science skills — backed up with version history.

## Skills

- **house-writing-style** (v1.0) — House prose conventions for chat and deliverables: bottom line up front, plain language, scannable structure, progressive disclosure.

## Import into Claude Science

To load a skill from this repo:

1. Copy the skill directory into your Claude Science skills folder
2. Reload the skill with `skill({skill: "skill-name"})`

For details on skill structure, see Claude Science documentation or the SKILL.md files.
